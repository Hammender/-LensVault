# JSON 图集采集插件示例

这个示例说明插件的文件结构和运行接口，不对应某个真实网站，也不会随主程序启用。目标接口应公开返回包含 `items` 和 `has_more` 的 JSON；每个条目包含稳定的 `id`、原始媒体 `url`，可选 `title` 和 `type`（`image` 或 `video`）。网站实际字段不同，需要在插件内适配。

本示例不声明登录凭据。它面向不用登录、按页就能下载图片或视频的网站。

## 安装

将本目录中的 `plugin.json`、`plugin.py`、`README.md` 放在 ZIP 根目录。在 PictureShow 的“采集插件”页由系统管理员上传、准备环境并启用。示例不需要额外 Python 库，也不会安装浏览器。

## 采集

绑定插件到站点和分类后，把分类 URL 设置为返回上述 JSON 的分页接口地址。运行时填写最多采集页数。采集结果进入统一待审核区，插件不负责去重和正式入库。

Telegram 频道采集是程序内置能力，使用采集中心原有的账号登录流程，不要做成这类插件。
