## ADDED Requirements

### Requirement: 图库图片文件大小持久化
系统 MUST 为展示图库图片保存原始文件大小（字节），并在新的直接上传、采集审核导入和 ZIP 导入路径中写入该值。

#### Scenario: 新图片导入
- **WHEN** 图片成功导入展示图库
- **THEN** 对应图库记录保存与导入载荷一致的文件字节数

#### Scenario: 旧记录兼容
- **WHEN** 系统读取尚未回填大小的历史图库图片
- **THEN** 读取成功且文件大小以未知值表示

### Requirement: 历史图库文件大小回填
系统 MUST 提供显式执行的一次性工具，以对象存储元数据回填缺失的图库文件大小，且默认不得修改数据库。

#### Scenario: 预演回填
- **WHEN** 管理员未传入写入确认参数执行回填工具
- **THEN** 工具报告可回填项目但不修改数据库

#### Scenario: 确认回填
- **WHEN** 管理员传入写入及确认参数执行回填工具
- **THEN** 工具仅更新缺失大小的记录并记录无法读取对象的失败项

### Requirement: 相似整理显示文件大小
系统 MUST 在展示图库相似整理的大图右侧信息栏显示当前图片的文件大小。

#### Scenario: 已知文件大小
- **WHEN** 用户打开具有文件大小的相似图片大图
- **THEN** 信息栏以可读的字节单位显示文件大小

#### Scenario: 文件大小未知
- **WHEN** 用户打开未回填文件大小的历史图片
- **THEN** 信息栏显示未知而不影响其他相似整理信息
