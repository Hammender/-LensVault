## ADDED Requirements

### Requirement: 后端按领域组织应用结构
系统必须（MUST）通过可测试的应用工厂组装 FastAPI 应用，并将生命周期、依赖、权限、响应转换、后台任务和业务路由从单一入口文件中分离。生产入口必须继续导出可由现有 Uvicorn 命令加载的 `app` 对象。

#### Scenario: 生产入口保持可加载
- **当** 使用现有 Uvicorn 模块路径导入后端应用
- **则** 系统能够获得 FastAPI `app` 对象，且无需修改启动命令

#### Scenario: 测试环境跳过外部资源启动
- **当** 测试通过应用工厂注入临时数据库和伪造服务
- **则** 系统不连接真实 MinIO、Qdrant、人脸模型、FFmpeg 或字幕服务

### Requirement: 外部接口保持兼容
结构重构后，系统必须（MUST）保持现有 API 路径、HTTP 方法、参数、请求体、响应 Schema、状态码和媒体 Range 行为，不得修改数据库表结构或现有数据。

#### Scenario: API 契约比较
- **当** 将重构后的规范化 OpenAPI 文档与重构前基线比较
- **则** 所有业务路径、方法、参数、请求体、响应和 Schema 均保持一致

#### Scenario: 路由匹配顺序保持一致
- **当** 比较重构前后的有序路由表
- **则** 具有潜在路径冲突的静态路由和动态路由保持原有匹配优先级

#### Scenario: 媒体范围请求保持一致
- **当** 客户端对图片、视频或字幕媒体资源发送合法或非法 Range 请求
- **则** 系统返回与重构前相同的状态码、范围头和响应长度规则

### Requirement: 权限必须显式且结果兼容
所有需要工作空间权限的修改接口必须（MUST）显式声明对应权限，认证上下文必须继续执行用户有效性、工作空间成员关系和对象隔离检查。

#### Scenario: 成员具有所需权限
- **当** 普通成员调用其已获得新增、修改或删除权限的对应接口
- **则** 系统允许该操作，行为与重构前一致

#### Scenario: 成员缺少所需权限
- **当** 普通成员调用其未获得权限的修改接口
- **则** 系统返回 HTTP 403，且不得修改任何工作空间数据

#### Scenario: 跨工作空间访问
- **当** 用户请求不属于当前工作空间的对象
- **则** 系统拒绝访问并保持现有未找到或禁止访问语义

### Requirement: 前端按领域保持状态和交互
前端必须（MUST）将应用壳、认证、工作空间及各业务页面拆分为类型明确的模块，同时保持现有 Hash 路由、页面切换状态、用户操作流程、中文文案和视觉效果。

#### Scenario: 页面切换保留领域状态
- **当** 用户在图库、人物或视频页面设置筛选、选择或编辑状态后切换到其他页面再返回
- **则** 需要由现有应用生命周期保留的状态不会因为组件拆分而重置

#### Scenario: Hash 地址保持兼容
- **当** 用户访问现有页面 Hash 或视频播放 Hash
- **则** 前端显示与重构前相同的页面和目标视频

#### Scenario: 页面样式保持一致
- **当** 用户在相同视口查看重构前后的关键页面和弹窗
- **则** 布局、选择器效果、响应式行为和交互状态不存在有意的视觉变化

### Requirement: 前端请求和本地存储协议保持兼容
前端 API 拆分后必须（MUST）继续统一注入认证 token 和工作空间信息，并保持现有请求函数名称、媒体 URL 处理、本地存储键和视频续传队列格式。

#### Scenario: 认证工作空间请求
- **当** 已登录用户在选定工作空间中调用业务 API
- **则** 请求携带与重构前相同的认证和工作空间信息

#### Scenario: 恢复历史上传队列
- **当** 浏览器中存在重构前保存的视频上传队列
- **则** 前端能够读取、规范化并继续展示或恢复该队列

#### Scenario: 无效队列数据
- **当** 本地存储中的上传队列缺少必要字段或包含无效值
- **则** 前端按现有容错语义忽略或修正无效记录，不影响应用启动

### Requirement: 重构必须具备回归测试护栏
项目必须（MUST）提供可重复执行的后端和前端测试命令，并覆盖结构重构最容易破坏的接口契约、权限、路由、请求客户端和上传队列逻辑。

#### Scenario: 无需启动开发服务器执行测试
- **当** 开发者执行后端测试、前端测试和前端生产构建
- **则** 测试无需主动启动前端或后端开发服务器即可完成

#### Scenario: 结构回归被测试发现
- **当** 路由、权限、请求头、本地存储格式或关键纯逻辑出现不兼容修改
- **则** 至少一个自动化测试失败并指出对应行为差异

### Requirement: 后续重构工作必须被保留
本次变更必须（MUST）在设计或任务文档中记录未纳入第一阶段的大型服务拆分、数据库迁移和规范工具计划，后续会话不得依赖临时对话记忆恢复这些工作。

#### Scenario: 后续会话继续规划
- **当** 开发者在新的会话中读取本变更文档
- **则** 能够识别大型媒体服务、Alembic、代码规范工具和组件测试的后续实施顺序
