# Telegram 会话、论坛主题与评论媒体采集

## 功能范围

Telegram 采集分类现在可以使用已登录账号能够访问的频道、群组或机器人私聊。会话选择使用 Telegram peer ID 保存，因此私有频道即使没有公开链接，也可以直接从会话列表选择。原有手工输入入口继续支持公开用户名、`t.me` 链接、私有邀请链接和数字 peer ID。

采集内容限定为图片和视频。每次启动脚本时可以只选择图片、只选择视频或同时选择两者；该选择不保存到分类。机器人私聊只处理图片和视频，不采集纯文本。

## 论坛主题

对于启用论坛模式的群组，分类创建器会自动读取主题列表，显示主题名称、主题 ID、置顶和关闭状态。选择某个主题后保存为独立分类，分类名称默认使用“频道名 / 话题名”，运行时只扫描该主题；也可以在列表不可用时手工输入主题 ID。主题名称只用于展示，主题 ID 才是稳定标识。

普通频道没有主题列表。频道绑定讨论组后，讨论组的论坛主题才可被查询。

## 评论区媒体

启动 Telegram 采集脚本时提供“采集频道评论区中的图片和视频”开关，默认关闭。手工输入引用时也会显示该选项；机器人和群组目标自动禁用。开启后，采集器在处理频道原帖时读取关联讨论线程，只下载评论中的图片和视频，并将它们送入现有待审核、去重和入库流程。评论元数据会保留原帖消息 ID、回复消息 ID、评论标记和发送者信息。

评论区无权限、评论被删除或 Telegram 限流时，原帖媒体仍继续采集，运行日志记录评论读取失败。热门帖子受评论数量和安全扫描上限保护。

## 权限与链接

公开频道具有 `@username`，可以使用 `https://t.me/username`。私有频道没有公开用户名，普通成员不能从频道 ID 反推出新的邀请链接；如果资料页不显示邀请链接，需要向管理员索取。已加入的私有频道可直接使用会话选择器，不需要再寻找链接。

会话和讨论组必须对当前登录用户可见。退出账号或 session 失效后，需要重新登录；程序不会代替用户加入频道，也不会生成无权限的邀请链接。

## API

- `GET /api/acquisition/telegram/dialogs`：读取当前账号会话列表。
- `GET /api/acquisition/telegram/dialogs/{peer_id}/topics`：读取论坛主题。
- `POST /api/acquisition/sources/{source_id}/telegram-channels`：创建 Telegram 分类，兼容 `channel_ref`，并接受 peer 和主题字段；媒体类型与评论开关在运行时提交。

分类创建只保存会话和话题目标。图片/视频选择以及评论区开关都在“启动采集”时设置，默认采集图片和视频且关闭评论区。数据库结构通过 Alembic 迁移 `20260905_dde49fc544b6_扩展_telegram_会话主题与评论媒体采集.py` 和 `20260905_364bf17881ef_移除分类级_telegram_媒体策略.py` 更新；部署后运行 `python -m alembic upgrade head`。
