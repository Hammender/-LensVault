# 前端规范

## 目录结构（`frontend/src/`）

| 路径 | 内容 |
| --- | --- |
| `frontend/src/main.tsx`、`frontend/src/App.tsx`、`frontend/src/ApplicationContent.tsx` | 入口、登录态与页面切换 |
| `frontend/src/pages/` | 页面：`Home`、`GalleryPage`、`SimilarityReview`、`AcquisitionCenter`、`PeoplePage`、`UploadPage`、`VideosPage`、`VideoPlayPage`、`Statistics` |
| `frontend/src/components/` | 复用组件：灯箱、确认框、可搜索下拉、权限编辑、工作区面板等 |
| `frontend/src/hooks/` | 页面数据与状态逻辑（`useGallery.tsx`、`usePeople.ts`、`useVideos.ts` 等） |
| `frontend/src/lib/` | 纯函数工具与单元测试（`*.test.ts`） |
| `frontend/src/api/` | 按模块拆分的请求函数，统一经 `frontend/src/lib/apiClient.ts` |
| `frontend/src/types/`、`frontend/src/types.ts` | 类型定义 |
| `frontend/src/styles.css` | 全局样式；部分页面/组件有同名 `.css` |

路由使用 hash（`#/gallery` 等），定义在 `frontend/src/lib/routing.ts`。

## 约定

- TypeScript/TSX 两空格缩进、双引号；组件 `PascalCase`。
- 复杂逻辑优先抽到 `frontend/src/lib/` 的纯函数并配测试，页面组件保持薄。
- 图标使用 `lucide-react`。
- 面向用户的文案使用中文（周边界面已是英文的除外）。
- 权限判断用 `frontend/src/lib/permissions.ts` 的 `hasPermission`，与后端权限保持一致。

## 视觉方向

- 项目以展示人物写真为主，美观优先，但列表页修正人物绑定必须高效（详情一键可达）。
- 图库与灯箱使用浅色/奶油色主题；深色只作对比稿，不作为默认。
- 图库卡片：人名完整显示在图片下方、不遮挡画面；不显示图片编号和普通标签；「详情」按钮常驻。

## 交付前

1. 运行 `npm run build`（含 `tsc -b` 类型检查）。
2. 有相关单元测试时运行 `npm test`。
3. 在浏览器中手工走一遍修改的流程（由 AI 自己完成，并说明验证了什么）；验证完关闭启动的程序。
