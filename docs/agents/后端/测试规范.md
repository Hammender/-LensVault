# 测试规范

## 后端

- 测试位于 `backend/tests/`，新增后端测试也放在这里；公共辅助在 `backend/tests/support/`，`backend/tests/conftest.py` 会把 `DATABASE_URL`、`DATA_DIR` 指向系统临时目录。
- 改动后运行受影响的测试；涉及通用行为时运行完整测试：

  ```bash
  python -m pytest backend/tests
  python -m pytest backend/tests/test_gallery_photo_id_search.py   # 单个文件
  ```

- 接口变化会使 `backend/tests/test_contract.py` 失败，按 `docs/agents/后端/后端规范.md` 更新契约快照。
- 迁移相关：`backend/tests/test_database_migrations.py`、`backend/tests/test_schema_sql.py`。

## 前端

- 单元测试用 vitest，放在 `frontend/src/` 下靠近功能的位置（现有均在 `frontend/src/lib/*.test.ts`）。
- 命令：`npm test`（Windows：`cmd /c npm.cmd test`）；前端改动还必须 `npm run build`。
- 已知：在 Asia/Shanghai 时区运行时有 2 个与 `24:00`/`00:00` 显示相关的既有失败，与具体改动无关（`tests/acquisitionRunForm.test.ts` 的 Shanghai 偏移序列化用例、`tests/utils.test.ts` 的 datetime-local 往返用例）；不要把它们算作新回归，但交付时如实说明。

## 测试后清理

每次完成 Python 测试或前端测试/构建后，及时删除本次产生的无用临时文件：系统临时目录中的 pytest/测试数据目录（如 `pictureshow-tests-*`）、项目内新产生的 `__pycache__`、`.pytest_cache`、覆盖率报告等。不得删除 `.env`、模型权重、虚拟环境、持久化数据目录及用户未授权清理的文件。交付说明中列出已删除项。

因环境、权限或时间无法执行的检查，必须在交付说明中写明未执行项与原因。
