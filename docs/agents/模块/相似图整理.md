# 相似图整理

## 业务目标

找出图库中近重复、镜像的图片，推荐保留质量更好的一张，由用户逐组确认删除或保留。

## 关键流程

1. **发起扫描**：`POST /api/gallery/similarity-scans`；扫描类型 `scan_type` 有 `normal` 与 `mirror`。
2. **特征**：整图向量用本地 `facebook/dinov2-base`（768 维，集合默认 `pictureshow_gallery_similarity_dinov2_base_v1`），辅以感知哈希、ORB 特征；结果存 `GallerySimilarityFeature`。
3. **分组**：`complete_link_clusters` 聚类；分组层级 `tier`（如 `near_duplicate`），审核状态 `review_status` 初始为 `pending`；质量评估给出推荐（`recommendation_status`）。
4. **审核**：`frontend/src/pages/SimilarityReview.tsx` 读取 `latest`/`overview`/分组列表，`PATCH .../groups/{group_id}` 提交处理结果；支持键盘操作（`frontend/src/lib/similarityReviewKeyboard.ts`）。
5. **自动删除计划**：镜像精确重复与普通近重复各有预览/选择函数（`select_exact_mirror_auto_delete_photo_ids`、`build_normal_near_duplicate_auto_delete_plan`），阈值见 `GALLERY_SIMILARITY_AUTO_DELETE_*`。
6. **过期**：图库照片或人物变化时调用 `mark_similarity_scans_stale` 标记扫描过期。

## 涉及文件

- 后端：`backend/app/services/similarity.py`、`backend/app/api/gallery.py`（similarity-scans 路由）、`backend/app/models/gallery.py`（`GallerySimilarity*`）、`backend/app/schemas/similarity.py`
- 前端：`frontend/src/pages/SimilarityReview.tsx`、`frontend/src/lib/similarityScanState.ts`、`frontend/src/lib/similarityReviewKeyboard.ts`、`frontend/src/types/similarity.ts`
- 测试：`backend/tests/test_gallery_similarity.py`

## 名词

相似图扫描、分组、成员、配对（`GallerySimilarityGroupPair`）、分组人物（`GallerySimilarityGroupPerson`）。

## 必须遵守的规则与常见坑

- 模型只从 `.env` 的 `GALLERY_SIMILARITY_MODEL_PATH` 加载，`local_files_only=True`，不会联网下载；不要改成自动下载。
- 自动删除会删除用户照片，属于危险操作：调整阈值或逻辑须说明影响并取得授权。
- 采集中心也有自己的相似候选（`AcquisitionSimilarityCandidate`），与图库相似图是两套，不要混淆。
- `tier` 的完整取值集合待确认（代码中可见 `near_duplicate`）。
