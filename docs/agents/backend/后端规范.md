# 后端规范

## 分层与目录（`backend/app/`）

| 路径 | 职责 |
| --- | --- |
| `backend/app/main.py` | 应用组装：创建应用、构建服务容器、`include_router` 注册各路由；保留部分旧导出以兼容测试 |
| `backend/app/application.py` | `create_app`：中间件、生命周期 |
| `backend/app/lifecycle.py` | 启动初始化，`initialize_database` 自动执行 `alembic upgrade head` |
| `backend/app/api/` | 路由处理函数，按模块拆分（`gallery.py`、`people.py`、`acquisition.py`、`acquisition_plugins.py`、`videos.py`、`subtitles.py`、`workspaces.py`、`system.py`、`statistics.py`），公共辅助在 `_helpers.py` |
| `backend/app/services/` | 领域逻辑（导入、人脸、Qdrant、存储、缩略图、相似图、采集、视频、字幕、任务等）；`container.py` 组装服务实例 |
| `backend/app/models/` | SQLAlchemy ORM 模型（按模块拆分） |
| `backend/app/schemas/` | Pydantic 请求/响应模型 |
| `backend/app/mappers/` | ORM 对象 → 响应 schema 的转换 |
| `backend/app/dependencies/context.py` | 登录态、当前工作区、权限校验（见 `docs/agents/modules/工作区与权限.md`） |
| `backend/app/http/media.py` | 媒体响应辅助 |
| `backend/app/core/config.py` | `Settings` 配置；`backend/app/core/timezones.py` 时区工具 |
| `backend/app/db.py` | 引擎、会话、`Base` |
| `backend/app/tools/` | 手动运行的运维/评测脚本，说明见 `backend/app/tools/README.md` |

## 代码风格

- Python 4 空格缩进；模块与服务文件 `snake_case`；Pydantic 与 ORM 模型 `PascalCase`。
- 路由函数保持薄：参数校验与权限后交给 service；优先小型辅助函数，避免深层嵌套。
- 面向用户的错误信息（`HTTPException.detail`）使用中文，与现有代码一致。
- 新增需要权限控制的路由，要在 `backend/app/dependencies/context.py` 的 `ROUTE_PERMISSION_MATRIX` 中登记。

## 配置与 `.env`

- 程序运行时只读取构造参数和 `.env`，不读取进程环境变量，也不读取 `.env.example`。
- `.env` 必须包含 `Settings` 的全部字段，缺任一字段启动即报错（`get_settings`）。
- `.env` 字段应与 `.env.example` 对应。
- 配置变更优先维护本地 `.env` 的完整字段和值；`.env.example` 只保留完整字段名和不泄露隐私的示例默认值。
- 新增配置时同步：`backend/app/core/config.py` 字段、`.env.example`。
- 不得把真实密钥提交到仓库；避免提交 `data/` 中的本地数据、模型下载文件。

## 接口契约快照

- `backend/tests/contracts/openapi.json` 与 `backend/tests/contracts/routes.json` 是 OpenAPI 和路由顺序的基线，由 `backend/tests/test_contract.py` 校验。
- 有意修改接口后，运行 `backend/tests/tools/capture_api_contract.py` 重新生成快照（`python backend/tests/tools/capture_api_contract.py`，无参数，直接覆盖两个快照文件），并在提交中检查 diff 只包含预期变化。
- 修改 API 时追踪前端调用方（`frontend/src/api/`、`frontend/src/types/`），保持兼容或写明迁移要求。
