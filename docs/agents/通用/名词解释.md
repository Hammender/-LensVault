# 名词解释

| 名词 | 含义 | 代码位置 |
| --- | --- | --- |
| 图库照片 | 正式入库的图片，主键即界面上的「图片编号」 | `backend/app/models/gallery.py`（`GalleryPhoto`） |
| 人物 | 被识别和绑定的对象，属于某个工作区 | `backend/app/models/people.py`（`Person`） |
| 未知人物 | 系统自动创建的人物（`is_unknown=True`，带 `unknown_serial` 序号），表示识别到人脸但未匹配已知人物；不能手动添加或绑定 | `backend/app/models/people.py`、`backend/app/api/gallery.py` |
| 样本 / 样本照片 | 人物的参考人脸图片，用于建立人脸索引 | `SamplePhoto`，`backend/app/services/face_index.py` |
| 人脸记录 | 一张图库照片中检测出的单个人脸及其绑定人物 | `FaceRecord`（`backend/app/models/gallery.py`） |
| 识别修正 | 用户在详情面板改绑人脸的记录 | `FaceRecognitionCorrection` |
| 人物标签 | 照片与人物的绑定（卡片上显示的人名） | `GalleryPhotoPersonTag`、`PersonTag` |
| 普通标签 | 与人物无关的标签；图库列表卡片上不显示 | `Tag`、`GalleryPhotoTag` |
| 图文 | 带富文本内容的照片（`rich-text` 接口） | `backend/app/api/gallery.py` |
| 预览图 / 缩略图 | 后端生成的列表用图：静态图按请求宽度归档到 160～2048 档位（默认 480），动图最长边 720，缓存在 MinIO | `backend/app/services/thumbnails.py` |
| 工作区（内容空间） | 数据隔离单位；每个用户自动有一个私人空间（`kind="private"`） | `backend/app/models/system.py`、`backend/app/dependencies/context.py` |
| 所有者 / 成员 | 工作区角色；`owner` 拥有全部权限，`member` 按 `can_*` 开关授权 | 同上 |
| 采集来源 / 分类 / 运行 | 采集中心的站点、站点下的采集目标、一次采集执行 | `backend/app/models/acquisition.py` |
| 采集素材 | 采集下载的待审核媒体，审核后导入图库或拒绝 | `AcquisitionAsset` |
| 导入批次 | 一次把素材导入图库的批量操作 | `AcquisitionImportBatch` |
| 采集插件 | 管理员上传的 ZIP 站点适配器，独立进程与独立 Python 环境运行 | `backend/app/services/acquisition_plugins/` |
| 相似图扫描 / 分组 | 图库内近重复或镜像图片的扫描结果与待处理分组 | `GallerySimilarityScan`、`GallerySimilarityGroup` |
| 字幕轨 | 视频的字幕记录，由语音识别 + 翻译生成 | `VideoSubtitleTrack`，`backend/app/services/subtitles.py` |
| 任务 | 后台长任务（导入、识别等）的进度记录 | `backend/app/models/tasks.py`、`backend/app/services/tasks.py` |
