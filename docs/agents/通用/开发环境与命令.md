# 开发环境与命令

## 运行环境

- Python 默认使用名为 `pictureshow` 的 Conda 环境；依赖清单为 `requirements.txt`、`requirements-dev.txt`，GPU 相关为 `requirements-face-cuda.txt`、`requirements-vision-cuda.txt`。
- 前端依赖见 `frontend/package.json`，Node 包管理用 npm。
- 依赖服务：MinIO（默认 `127.0.0.1:19000`）和 Qdrant（默认 `127.0.0.1:16333`，gRPC `16334`），默认值见 `backend/app/core/config.py`，实际值以 `.env` 为准。
- 端口：后端 8000，前端 7749；Vite 把 `/api` 代理到后端，可用环境变量 `VITE_BACKEND_PORT`、`VITE_FRONTEND_PORT` 覆盖（`frontend/vite.config.ts`）。

> 启动程序需用户授权（见 `AGENTS.md`）。以下命令供用户手工执行或授权后使用。

## 后端

Linux / macOS：

```bash
conda activate pictureshow   # 或项目自建的 venv
python -m uvicorn app.main:app --app-dir backend
```

Windows（PowerShell）：

```powershell
conda activate pictureshow
python -m uvicorn app.main:app --app-dir backend
```

启动命令不加 `--reload`，避免编辑模型或迁移时自动对真实库执行迁移。健康检查 `GET /api/health`，接口文档 `http://127.0.0.1:8000/docs`。

## 前端

`frontend/package.json` 中的脚本：`dev`（vite）、`build`（`tsc -b && vite build`）、`preview`、`test`（`vitest run`）。

Linux / macOS：

```bash
cd frontend
npm install
npm run dev
npm run build
npm test
```

Windows（PowerShell 下 `npm` 受执行策略限制时）：

```powershell
cd frontend
cmd /c npm.cmd install
cmd /c npm.cmd run dev
cmd /c npm.cmd run build
cmd /c npm.cmd test
```
