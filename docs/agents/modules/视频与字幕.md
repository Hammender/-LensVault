# 视频与字幕改动规范

## 改动前阅读

上传、播放、字幕、来源和视频素材包见 [视频与字幕说明](../../modules/视频与字幕.md)。配置默认值与升级步骤维护在该业务文档，运维工具见 `backend/app/tools/README.md`。

## 工作约束

- 视频人物与图库人物分开处理，不共享人脸识别流程。
- 转码等耗时处理放后台，不在请求线程中同步执行。
- FFmpeg 与模型路径读取配置，不硬编码本机路径。
- 上传后台的播放优化失败不得阻断后续字幕任务；采集和素材包导入仍应接收优化异常并记录结果。
- 修改视频处理时保留原始入库哈希的语义；替换存储对象后同步当前内容哈希。
- 修改来源或入库流程时保持首次来源及操作人快照，不因重试或重复入库覆盖。
- 修改素材包流程时保持解压前校验、资源限制、临时文件清理和工作区隔离。
- `backend/app/main.py` 保留视频兼容包装函数，改动前追踪旧调用方与测试。
- 测试启动的字幕翻译服务由本次测试负责停止，不能遗留后台进程。
