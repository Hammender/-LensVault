# 相似图整理改动规范

## 改动前阅读

扫描、分组、审核与过期流程见 [相似图整理说明](../../modules/相似图整理.md)；模型安装和配置见 `docs/gallery-similarity.md`。

## 工作约束

- 模型只从 `.env` 配置的本地路径加载，保持 `local_files_only=True`，不改成自动下载。
- 自动删除涉及用户照片，调整其阈值或逻辑前说明具体影响并遵守用户授权范围。
- 采集相似候选与图库相似图分开处理，不混淆模型和操作对象。
- 修改图库导入、删除或人物绑定时，保持相似图扫描结果的过期标记。
- 修改分组逻辑时保持普通扫描与镜像扫描各自的分组语义，针对受影响分支验证。

## 关键代码与验证

- 后端入口：`backend/app/services/similarity.py`、`backend/app/api/gallery.py`、`backend/app/schemas/similarity.py`。
- 前端入口：`frontend/src/pages/SimilarityReview.tsx`、`frontend/src/lib/similarityScanState.ts`、`frontend/src/lib/similarityReviewKeyboard.ts`。
- 按改动运行 `backend/tests/test_gallery_similarity.py` 及相应前端测试；前端改动执行构建。
