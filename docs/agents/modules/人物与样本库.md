# 人物与样本库改动规范

## 改动前阅读

标签页面行为、样本与识别流程见 [人物与样本库说明](../../modules/人物与样本库.md)。模型方案与评测方法见 `docs/人脸识别技术方案与准确率评审说明.md`。

## 工作约束

- 未知人物由系统创建，不允许手动添加或绑定。
- 模型与阈值以 `.env` 为准，不以代码默认值或某台设备的历史记录推断当前配置；修改阈值前运行对应评估。
- 更换模型时核对向量维度并重建相应索引，不混用不同模型或版本的向量。
- 修改人物修正逻辑时保持修正记录完整；涉及样本变更时保持相关人物中心向量更新。
- 识别异常案例与普通修正独立；默认只记录、不改绑、不新增样本，仅指定正确人物时允许选择同事务改绑。库外人物与仅排除指定人物的结论不能混同或转为正样本。案例原图和识别快照不随源图、人脸或人物删除；时间与坐标约定见 [识别异常案例说明](../../modules/识别异常案例.md)。
- 修改普通标签筛选时使用人物与标签的直接绑定关系，不用同图共现替代；避免逐个人物查询标签。
- 人物详情的异步响应只能更新当前选择的人物；切换人物时丢弃未上传预览，防止旧数据覆盖新选择。
- 前后端的普通标签、样本及人物维护权限保持一致；绑定、解绑或删除后刷新受影响数据。
- 运行写数据的工具前核对目标数据库、Qdrant 和 MinIO，遵守用户授权范围。工具说明见 `backend/app/tools/README.md`。
