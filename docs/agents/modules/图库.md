# 图库改动规范

## 改动前阅读

业务流程、接口、预览策略、来源及 ZIP 格式见 [图库说明](../../modules/图库.md)。修改相关行为时同步维护该文档。

## 工作约束

- 保持浅色主题、筛选默认展开、人名完整展示和常驻详情入口；界面调整不能削弱识别修正效率。
- 灯箱保留右侧竖向信息栏，不改成横向底栏，不把完整修正面板塞进灯箱。
- 列表使用派生预览，不直接加载原图；静态预览和动图预览的处理路径不要混用。
- 不允许手动添加或绑定系统未知人物。
- 改动导入或人物修正流程时，保持相似图结果过期标记的调用。
- 修改列表参数时同步前端调用方与接口契约；调整瀑布流、范围选择或灯箱顺序时，分别验证各自的顺序语义。
- 来源和素材应在同一事务提交；重复入库不得覆盖首次来源或入库人。来源摘要查询不能逐图加载详情。

## 关键代码与验证

- 后端入口：`backend/app/api/gallery.py`、`backend/app/services/importer.py`、`backend/app/services/thumbnails.py`。
- 来源与素材包：`backend/app/services/provenance.py`、`backend/app/services/media_archives.py`、`backend/app/api/provenance.py`。
- 前端入口：`frontend/src/pages/GalleryPage.tsx`、`frontend/src/components/PhotoLightbox.tsx`、`frontend/src/hooks/useGalleryLightbox.ts`、`frontend/src/components/MediaSource.tsx`。
- 按改动运行 `backend/tests/test_gallery_*.py`、`backend/tests/test_media_provenance.py` 及相应前端测试；前端改动执行构建。
- 识别与相似图改动另见 [人物与样本库规范](人物与样本库.md)、[相似图整理规范](相似图整理.md)。
